### 👨‍💻 Sobre mí

- 🏢 Llevo CodeByMihai desde Madrid.
- 🖥️ Hago aplicaciones de escritorio para Windows y Linux, de la interfaz al instalador.
- 🌐 Hago webs a medida para negocios y comunidades.
- 🎮 Pongo a punto PCs para gaming y streaming con mi propio optimizador.
- 🏁 Desarrollo las herramientas del club de simracing CEC Contra el Crono.
- 📫 Escríbeme a **info@codebymihai.com**.
